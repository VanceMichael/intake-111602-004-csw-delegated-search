# 资料服务接口

查询参数顺序不影响来源匹配。区域目录与根目录会返回相同本地 identifier，区域目录还指回根服务；覆盖状态与异常独立于命中记录。

CSW 响应保留 XML 标准字段。/capabilities 和 /regional/csw 是既有网关提供的 JSON 调试视图，含委托路径、异常及本次查询覆盖；不能将其 complete:false 转为空结果。来源标识空间由服务入口区分。

本地服务的资料入口为 `/csw?service=CSW&request=GetRecords`。`fixtures/ordinary.json` 记录当前可预览的资料；`fixtures/transition.json` 保存资料源连续两个发布日期。调用 `POST /control` 并传入 `{"action":"advance"}` 推进发布日期，`inspect` 返回实际请求记录，`reset` 恢复本地源；控制入口不属于远端标准协议。来源分段、延迟和断连均可用场景条目的 `chunks`、`delayMs`、`disconnect` 配置，不需要依赖实际网络故障。

原件目录采用内容摘要寻址，接收凭据独立记录来源、媒体类型和预览结果。单份资料接收不表示来源范围已经读完，也不推断缺失资料的业务含义。
